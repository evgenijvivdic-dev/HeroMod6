ГЕРОЙ-ЧЕЛОВЕК ДЛЯ VICE CITY - установка

Нужно: Vice City 1.0, Ultimate ASI Loader (dinput8.dll), Visual Studio 2022 с компонентом
"Разработка классических приложений на C++", Plugin-SDK (GitHub: DK22Pac/plugin-sdk), Python 3.10+.

1. СБОРКА ПЛАГИНА: build.bat
   - Создайте рядом с build.bat файл sdk_path.txt с одной строкой: путь к папке Plugin-SDK
     (или задайте переменную среды PLUGIN_SDK_DIR).
   - Необязательно: game_path.txt с путём к папке игры, тогда HeroMod.asi скопируется туда сам.
   - Если у SDK нет собранной plugin_vc.lib, соберите проект plugin_vc из plugin_sdk.sln (Release, Win32).
   - Запустите build.bat. Результат: Release\HeroMod.asi. При ошибках смотрите build_log.txt:
     чаще всего дело в строках с "// VERIFY" в Source\HeroMod.cpp (имена из заголовков SDK).
2. Положите в папку игры (рядом с gta-vc.exe):
      dinput8.dll   (ASI Loader)
      HeroMod.asi
      папку Hero\
      start_hero.bat
3. Запустите игру и загрузите сохранение. Через несколько секунд в папке игры появится state.json.
4. Запустите start_hero.bat. При первом запуске он поставит зависимости и спросит ключ API
   (ключ сохраняется в Hero\key.txt - не передавайте эту папку другим).

Клавиши в игре:
  F9  поговорить с героем          F10  автономия героя (в игре же аварийно прерывает действие)
  F5  свободная прогулка (без розыска)   F6/F7  больше/меньше людей и машин
  F8  быстрое время суток          F3/F4  запомнить точку / вернуться в неё

Свой персонаж: persona.json в папке игры (поля как в Hero\human.py -> DEFAULT_PERSONA).
Если клавиши не реагируют, запустите start_hero.bat от имени администратора.
Нет state.json - плагин не загрузился (проверьте dinput8.dll, версию игры 1.0 и расположение .asi).

САМЫЙ ПРОСТОЙ СПОСОБ (без установки Visual Studio): автосборка на GitHub
   1. Создайте репозиторий на github.com и загрузите в него всё содержимое этой папки
      (включая скрытую папку .github).
   2. Вкладка Actions -> Build HeroMod.asi -> Run workflow.
   3. После зелёной галочки скачайте HeroMod из раздела Artifacts (внутри HeroMod.asi).
   Если сборка красная, откройте лог и пришлите ошибки.
